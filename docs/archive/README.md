# Documentation Archive

This directory is designated for historical, superseded, or deprecated documentation artifacts retained for academic audit trail purposes.

## Archive Policy

1. **Active Canonical Documentation:** Current and authoritative project deliverables reside in:
   - `docs/01-requirements/`
   - `docs/02-architecture/`
   - `docs/03-sprints/`
   - `docs/04-testing/`
   - `docs/05-devops/`
   - `docs/reports/`
2. **Archival Eligibility:** Files are archived here only when their historical value justifies retention while newer or canonical deliverables supersede them.
3. **Immutability:** Archived documents are preserved for audit purposes and should not be modified without explicit documentation of the rationale.

*No active deliverables have been deprecated or moved to this archive during the November 1, 2026 documentation consolidation.*
